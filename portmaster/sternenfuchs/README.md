## Sternenfuchs prototype

ARM64 / PortMaster bring-up packaging for the open-source Star Fox Enhanced
runtime. No Nintendo ROM or ROM-derived runtime data is included.

Copy a supported legally obtained Star Fox/Starwing `.sfc` or `.smc` ROM into
`ports/sternenfuchs/`. The upstream runtime validates it and creates
`Starfox-Assets.BIN` locally.
